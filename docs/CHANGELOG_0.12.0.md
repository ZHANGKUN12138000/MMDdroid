# MMDroid Studio 0.12.0 Changelog

- Added adjustable character normal smoothing presets and custom angle/strength controls.
- Added original-normal restoration and scene persistence for smoothing settings.
- Added texture quality presets controlling render pixel ratio, trilinear mipmaps and anisotropic filtering.
- Added hybrid per-pixel transparency using alpha hash where supported.
- Improved PBR role separation and texture color preservation to reduce gray skin/clothing.
- Improved hair with anisotropic physical highlights and tangent generation.
- Added Oily Skin and Silicone Skin rendering pipelines with distinct specular/scattering responses.
- Upgraded Android versionCode to 13 and versionName to 0.12.0.
