# 0.7.0 Changelog

- 人物导入新增 ZIP/RAR 模型包。
- ZIP 解压后保持包内相对目录。
- RAR/RAR5 使用 Junrar 8.1.1 解包。
- 模型包自动选择主模型：PMX > PMD > FBX > GLB > GLTF > OBJ。
- 直接选择 PMX/PMD/FBX 后自动进入同级资源目录授权与递归扫描。
- SAF 目录权限持久化。
- 贴图匹配由“仅文件名”升级为“主模型目录 + 相对路径”，文件名仅作为后备。
- 导入后显示资源数 / 贴图数统计。
- 场景中若来源是 ZIP/RAR，只记录原始压缩包 URI；恢复场景时会重新解包。
- 骨骼树继续默认收起，仅手工展开。
