# MMDroid Studio 0.2.0 Change Log

- Replaced WebView-only file input path with native Android SAF bridge.
- Added persistent document URI storage for scene restoration.
- Added native scene JSON save dialog.
- Pinned Three.js to r171 for built-in MMDLoader/MMDAnimationHelper compatibility.
- Added left scene hierarchy and right property inspector.
- Added independent hide/show for top/left/right/bottom UI and collapsible property groups.
- Added full XYZ transform editing.
- Added additive per-bone position and rotation offsets.
- Added left/right eye quick offsets.
- Added IK chain and IK link editing.
- Added Key / Fill / Rim lighting, hemispheric ambient, ACES exposure.
- Added shadow map resolution, bias, normal bias, radius.
- Added static shadow-cache bake/freeze and manual rebake.
- Added environment/floor/fog controls.
- Added `.mmdscene.json` save/load with resource URI references.
