# MMDroid Studio 0.3.0 Change Log

- Changed all four main panels to edge-arrow collapse/restore interaction.
- Removed the old dedicated show/hide UI dock.
- Switched normal rendering to WebGLRenderer; OutlineEffect is now optional.
- Added render visibility repair for SkinnedMesh and materials.
- Changed eye correction from XYZ position offsets to eye pitch rotation.
- Added selection-driven Inspector filtering.
- Added nested scene folders backed by THREE.Group.
- Added Stage and Accessory object categories.
- Added accessory-to-bone attachment.
- Added hierarchical bone tree.
- Added material inspector/editor.
- Added dedicated IK Inspector nodes.
- Added HDRI/PMREM environment lighting.
- Added EffectComposer pipeline with Unreal Bloom, SSAO and Bokeh DOF.
- Added optional Ammo/MMD rigid-body physics controls and skirt/hair profile.
- Added editor keyframes and scrollable multi-track timeline with VMD key markers.
- Upgraded scene manifest to version 3.
